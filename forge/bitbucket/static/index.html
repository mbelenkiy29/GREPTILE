Connect OpenReview

In OpenReview, open Settings → Code providers and create a five-minute Bitbucket authorization for your workspace. Paste it here while signed in as this Bitbucket workspace’s owner.

Connecting grants the OpenReview app access to repository contents, pull requests and comments in this Bitbucket workspace. Select repositories and configure review behavior in OpenReview after connection. Automatic approval is unavailable.

Your configured OpenReview server stores authorized repository indexes, review data and encrypted app credentials. Source context is sent to its configured model provider during reviews.

The code is single use and expires after five minutes. No account password is needed.

You can revoke an unused code or disconnect this integration in OpenReview. Uninstalling the Forge app also disables its connection and repositories.

Link personal identity

In OpenReview Settings → Personal setup, generate a personal identity code for this connection. This verifies the account you are signed in as and its read access to the selected repository. OpenReview stores your short-lived token encrypted for at most one hour and rechecks access before cross-repository review or publication. No workspace-owner role is needed. Disconnect in OpenReview or confirm again after expiry.
