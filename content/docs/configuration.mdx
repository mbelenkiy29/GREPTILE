Review settings come in layers, and each key is resolved on its own: built-in defaults, then the organization's **Review defaults**, then the repository's settings in the dashboard, then `openreview.json` in the repository root. The file wins.

```json
{
  "mode": "deep",
  "ignore": ["**/__generated__/**"],
  "rules": ["Public API handlers validate their input with zod."]
}
```

## Where settings show up

The review summary on the pull request reports an invalid `openreview.json`. In the dashboard, each repository's settings page shows every effective value and which layer it came from (default, organization, repository, or file).
