# Code of conduct

OpenReview adopts the **Contributor Covenant, version 2.1** as its code of conduct for everyone taking part in the
project: in issues, pull requests, discussions, reviews, and any other project space, and when representing the
project elsewhere.

Read the full text at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>. In short: we pledge to make
participation harassment-free for everyone; we expect empathy, respect for differing viewpoints, constructive
feedback, and accountability for mistakes; and we do not accept sexualized language or imagery, trolling, insulting or
derogatory comments, personal or political attacks, harassment in public or private, publishing others' private
information without permission, or other conduct that is inappropriate in a professional setting.

## Reporting

Report behavior that violates the code of conduct privately to the project maintainers, through the contact listed on
the repository owner's GitHub profile, or by GitHub's **Report content** feature for a specific comment. Do not use a
public issue. Reports are reviewed promptly and kept confidential; reporters will not face retaliation.

## Enforcement

Maintainers enforce the code of conduct following the Contributor Covenant 2.1 enforcement guidelines (correction,
warning, temporary ban, permanent ban), choosing the response that fits the impact of the behavior.
