October 4, 2026. A durable regression demonstrated stale graph edges when an unchanged importer’s target appeared in the next inventory. The former SHA/version skip kept its unresolved `total.js` edge after `total.ts` was added. Identical importer source cannot by itself prove that its resolved dependencies are unchanged.

The shared mapper now records original relative specifiers and resolved paths. On each batch, the worker re-resolves those specifiers against the exact job manifest. It reparses an unchanged importer only if a target’s resolution changed or its receipt is missing/mismatched. Package references and computed imports retain their documented boundaries. `INDEX_GRAPH_VERSION=3` makes legacy files acquire receipts on their next authorized index refresh.

Receipts live in `graphModuleReferences`, indexed by repository/path and bound to source SHA plus graph version. They are written atomically with the indexed file/graph and removed with that file. A bounded internal query reads only the current 20-file batch; ordinary repository metadata queries do not collect all receipts. Up to 500 unique references and 64KB UTF-8 are retained per file. An oversized receipt is omitted, disabling incremental skipping for that file rather than falsely certifying partial coverage. No blanket reindex is scheduled by deployment.

The dedicated-table/batch shape avoids adding potentially large receipt arrays to repository-wide metadata collection. The chosen receipt and batch bounds remain below the documented document and transaction limits ([Convex limits](https://docs.convex.dev/production/state/limits)); this is a bound check, not a large-repository load test.
