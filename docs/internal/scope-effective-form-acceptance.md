# Effective values in workspace and team forms

The team defaults form previously displayed its stored settings wholesale (or built-in defaults if no row existed). Unchecked override fields therefore could display dormant values instead of the workspace values used by the review engine. For example, workspace confidence 97% and a disabled team confidence override saved at 60% would show 60% despite reviews using 97%.

`src/review-settings.ts` now supplies one selected-key resolver to `convex/scopes.ts` and `app/dashboard/scopes.tsx`. The form displays effective workspace → team values, retaining the explicit override checkbox state. Dormant stored values are preserved; explicit empty selections still override the parent. Existing repository overrides and Sync from parent behavior remain intact. No schema migration or settings mutation is required.

Regression checks cover the conflicting confidence example, independent maximum-comment override, missing team settings, explicit empty summary sections and restored inheritance.
