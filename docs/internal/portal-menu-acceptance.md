# Portal menu keyboard acceptance

October 4, 2026. Computer use on the current hosted portal found that pressing Escape left the workspace disclosure open. `PortalDisclosure` now keeps semantic native details/summary controls, closes on Escape and returns focus to its summary, dismisses on pointer interaction outside the disclosure, and uses a shared native disclosure name to prevent simultaneous workspace/profile panels. React effects remove their document listeners on unmount. Server-rendered workspace actions and personal links remain inside the disclosure.

Local validation: 172 Node tests and 142 Convex tests pass; lint, typecheck and production build pass. This change adds no inference or provider calls. Hosted deployment and browser acceptance are recorded below when verified. This is a particular keyboard/menu requirement, not evidence of the complete portal/provider/OS acceptance matrix.
