Its deployed provider factory calls an internal action that requires the author's existing confirmed identity for this exact repository/connection. It mints the same single-repository read-only metadata/contents/PR token, verifies repository/namespace identity, reads the target user's native collaborator permission and accepts only matching immutable IDs with `write` or `admin`. Unlinked, expired or revoked identities are denied. App 401/403/500, invalid responses, native read-only/custom roles and different user IDs cannot invoke or pass the fallback.
