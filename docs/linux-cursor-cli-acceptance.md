October 4, 2026. Installed Cursor Agent `2026.10.01-e373342` inside the isolated Ubuntu aarch64 acceptance VM using the installer obtained from `https://cursor.com/install`, following [Cursor's official installation documentation](https://cursor.com/docs/cli/installation). The downloaded script was inspected before execution. It installs `agent` and `cursor-agent` links under the guest user's `.local/bin`; it does not install the desktop `cursor` command. No host credentials, repository checkout or agent authentication was copied.
