# OpenReview mark

Four lines of code with an ember dot pinned to the third: a finding on a line. Designed with the [logo-design skill](https://github.com/kaankiziltug/logo-design-skill) (MIT) and pixel-fitted for 16 and 20 px.

| File | Use |
|---|---|
| `openreview-mark.svg` | Master, ink and ember: 24 px and up, except at multiples of 16 |
| `openreview-mark-header.svg` | Header cut for exactly 20 px (the in-app `Mark`); crisp at 2x |
| `openreview-mark-small.svg` | Small cut on the 16 px grid: `app/icon.svg` and the artwork in `app/apple-icon.png` |
| `openreview-favicon.svg` | 16 px drawing on an ink tile, built into `app/favicon.ico` (16/32/48) |
| `*-mono.svg` | One colour, for print or places the ember can't be reproduced |
| `*-reversed.svg` | Light lines (thinned 1 unit) with the ember dot, for static artwork on ink |

Colours: ink `#26251e`, light ink `#edecec`, ember `#f54e00`. See the Brand section of `DESIGN.md` for usage rules.
